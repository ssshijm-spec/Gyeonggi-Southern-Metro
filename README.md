# 경기남부광역철도 성사 · 온라인 행동

제5차 국가철도망 구축계획에 **경기남부광역철도**(서울–성남–용인–수원–화성)가 반드시 반영되도록, 주민들이 함께 행동할 수 있는 모바일 중심 원페이지 웹앱입니다.

## 기능
1. **경기도 청원 동의** — 청원 페이지로 바로 이동
2. **정치인 민원 문자** — 문구(예시 4종 또는 직접 작성)를 고르고, 정치인을 드롭다운에서 선택하면 모바일에서 문자앱이 열리며 내용이 자동 작성됩니다. 전체 일괄 발송도 지원.
3. **민원 접수** — 국토교통부·경기도청·국민신문고 민원 페이지 링크
4. **커뮤니티** — 네이버 카페 / 카카오톡 오픈채팅 참여
